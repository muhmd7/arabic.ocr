رفع التطبيق من الهاتف فقط (GitHub Pages):
1) افتح github.com من متصفح الهاتف وأنشئ حساباً مجانياً ثم مستودعاً جديداً (New repository) باسم arabic-ocr، واجعله Public.
2) Add file ← Upload files، وارفع الملفات الأربعة: index.html و sw.js و manifest.webmanifest و icon.svg ثم Commit.
3) Settings ← Pages ← Branch: main ← Save. بعد دقيقة يظهر الرابط: اسمك.github.io/arabic-ocr
4) افتح الرابط مرة واحدة وأنت متصل، وانتظر "جاهز" (ينزّل حوالي 15 ميغابايت).
5) آيفون: مشاركة ← إضافة إلى الشاشة الرئيسية. أندرويد: القائمة ← تثبيت التطبيق.
بعدها يعمل بدون إنترنت.
